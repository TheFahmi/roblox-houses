# Luxury Houses Showcase (Roblox)

5 rumah unik dengan interior mewah. Buka di Roblox Studio, publish, jelajah.

## Isi
- `houses.rbxlx` — place file
- `generate_houses.py` — generator (stdlib only)
- `HouseLogic.lua` — pintu auto-buka, bohlam pulse

## Rumah
1. Modern Cube — kaca + putih, chandelier
2. A-Frame Chalet — kayu, fireplace
3. Castle — tahta emas, menara
4. Villa L — kolam renang, dining set
5. Dome — kubah kaca, round bed

## Pakai
Roblox Studio → File → Open from File → `houses.rbxlx` → Publish.

Regen: `python3 generate_houses.py`.
